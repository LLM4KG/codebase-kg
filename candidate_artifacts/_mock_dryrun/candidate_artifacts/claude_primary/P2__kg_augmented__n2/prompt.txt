## Task

Add a `restoreAllTrash` reducer action to the note slice (`src/client/slices/note.ts`) that sets `trash: false` on every trashed note. Then add a "Restore All" button to the NoteList component (`src/client/containers/NoteList.tsx`) that appears alongside the existing "Empty Trash" button when the user is viewing the Trash folder.
