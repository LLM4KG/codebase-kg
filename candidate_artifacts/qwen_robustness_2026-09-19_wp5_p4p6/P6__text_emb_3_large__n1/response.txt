Looking at the code, I can see that the issue is in the `CategoryList` component where duplicate category checking is done with case-sensitive comparison. The problem is in two places:

1. `onSubmitUpdateCategory` - when renaming a category
2. `onSubmitNewCategory` - when adding a new category

Both functions use `categories.find((cat) => cat.name === category.name)` which does exact case-sensitive matching. I need to change this to case-insensitive comparison.
